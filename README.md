# Gugak CLaMP Benchmark Pilot

2026-2 NLP homework repository for zero-shot Gugak text-to-audio retrieval with CLaMP 3.

## Main files

- `archive/ai_assisted/PILOT_FINAL_REPORT.md`: consolidated pilot analysis draft
- `pilot_dataset.csv`: 33 matched Validation audio records and descriptions
- `h1_retrieval_results.csv`, `h2_retrieval_results.csv`: retrieval results
- `scripts/`: dataset preparation and evaluation code
- `artifacts/`: saved embeddings, similarities, and experiment metrics
- `archive/ai_assisted/`: AI-assisted stage reports, translation material, and validation notes

The archived report and the dataset retain the AI-use provenance needed to interpret and reproduce the experiment.
